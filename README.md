# 抽象代数学习笔记

这是以课程课件为主、杨子胥《近世代数（第二版）》为参考的 ElegantBook 中文笔记。第一章已整理定义、定理、证明和代表性例题；第二、三章目前只是群论目录框架。

- 阅读成品：`notes/abstract-algebra.pdf`
- 主文件：`notes/abstract-algebra.tex`；正文：`notes/chapters/`
- 个人批注：`temp/ch1/1.1.md` 等，按章、节分别填写
- 课件与书籍的来源定位：`book/page_index.md`

例如，阅读“映射与变换”时，可在 `temp/ch1/1.2.md` 写下自己的理解、证明思路与疑问。若希望以后自动扫描到该草稿，将文件开头的 `needs_organization` 改为 `true`；也可以直接指定小节要求整理。原始批注会保留。

在 `notes` 目录下用 XeLaTeX 编译主文件两次，即可更新 PDF。第二、三章的标题暂参考教材，并非已确认课程范围。
